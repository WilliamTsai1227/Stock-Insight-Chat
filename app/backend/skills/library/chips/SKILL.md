# 籌碼分析（台股）

## 資料蒐集

查詢期間預設為**最近 20 個交易日**，並與前 60 個交易日比較。每個數字都要註明資料日期。

1. **三大法人買賣超**（證交所／櫃買中心公布）：外資、投信、自營商每日與累計買賣超張數，
   以及外資持股比率的變化。
2. **信用交易**：融資餘額、融券餘額、券資比，以及近期增減；是否接近融資維持率斷頭區。
3. **股權分散**（集保結算所，每週公布）：千張大戶持股比率、400 張以上大戶比率、
   散戶（1–10 張）人數與持股比率的週變化。
4. **主力與分點**：近期主要買超／賣超券商分點（若查得到），是否有集中特定分點的現象。
5. **其他**：借券賣出餘額、當沖比率、董監持股與質押比率、近期董監或大股東申報轉讓。
6. 同期間股價與成交量走勢，用來對照籌碼變化。

使用者若上傳籌碼截圖或試算表，**以附件為準**，網路資料用來補足缺漏的期間。
查不到的項目寫「查無資料」，不可推測數字。

## 分析與輸出

### 1. 籌碼結論
一句話：籌碼**集中／中性／渙散**，主導買盤（或賣壓）來自誰。

### 2. 三大法人動向
表格：法人別｜近 5 日｜近 20 日｜近 60 日累計買賣超（張）。
說明外資與投信是否同向、是否出現連續買超／賣超、轉折點在哪一天。

### 3. 信用交易
融資、融券餘額與增減表；解讀散戶槓桿是否過熱（股價跌但融資增＝籌碼凌亂）、
券資比高低與軋空可能。

### 4. 大戶與散戶結構
千張大戶比率與散戶人數的週變化趨勢。大戶比率上升＋散戶人數下降＝籌碼集中。

### 5. 主力與特殊訊號
分點集中度、借券賣出、當沖比率、董監質押與申報轉讓中值得注意的項目。

### 6. 價量與籌碼對照
籌碼變化是否與股價、成交量一致（例如價漲量增且法人買超＝健康；價漲但法人賣、融資增＝風險）。
