# 財報解讀（改編自 Anthropic earnings-analysis skill）

## 資料蒐集

**訓練資料一定過時，不可用記憶中的財報。** 依序執行：

1. 先確認今天日期，搜尋「[公司] 最新 財報」「[公司] 法說會」，找出**最近一次**財報公布日。
   公布日若距今超過 3 個月，代表沒找到最新的，換關鍵字再查。
2. 蒐集本季資料：
   - 損益：營收、毛利率、營業利益率、稅後淨利、EPS，各自的**季增（QoQ）與年增（YoY）**
   - 台股另查：**月營收**（最近 3 個月）、業外損益是否異常
   - 分部／產品／地區營收結構（例如製程別、應用別）
   - 現金流與資本支出、存貨天數、應收帳款天數
3. **市場預期**：法人共識（EPS、營收）、公司上一季給的本季財測。註明預估來源與日期。
4. **公司說法**：本次法說會的下季財測、全年展望、資本支出計畫、管理層對需求與價格的評論。
5. 財報公布後的股價反應與主要法人評等調整（若有）。

使用者若附上財報 PDF、法說會簡報或截圖，**以附件為第一手來源**，網路資料用來補預期與市場反應。

## 分析與輸出

### 1. 一句話結論
開門見山：本季**優於／符合／低於**預期，主因是什麼，對投資論點的影響。

### 2. 關鍵數字 vs 預期
Markdown 表格：項目｜本季實際｜市場預期（或公司財測）｜差異（金額與％）｜QoQ｜YoY。
至少包含營收、毛利率、營業利益率、EPS。**每個預期數字都要寫出處與日期。**

### 3. 優於／低於預期的原因
逐項解釋差異來自哪裡（價格、量、產品組合、匯率、一次性項目）。只寫新資訊，不重述公司背景。

### 4. 營運細節
分部／產品結構變化、利潤率走勢、費用控制、現金流與資本支出、存貨與庫存循環。

### 5. 財測與展望
新舊財測對照表（上次 vs 這次），說明調升／調降的方向與理由；管理層語氣的變化。

### 6. 對估值與投資論點的影響
預估是否需要上修或下修、哪些論點被強化或削弱、接下來要追蹤的指標與催化劑。

### 7. 來源
條列財報、法說會簡報、新聞稿、共識預估的出處與日期，網址做成可點的連結。
