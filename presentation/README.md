# 面試簡報 — Stock Insight Chat

## 開啟方式
直接用瀏覽器打開 [`index.html`](./index.html)（雙擊即可，不需任何伺服器或網路）。

## 操作
| 按鍵 | 功能 |
| :--- | :--- |
| `→` / `空白鍵` / 點畫面右半 | 下一頁 |
| `←` / 點畫面左半 | 上一頁 |
| `N` | 顯示 / 隱藏**講稿**（每頁的口說重點 + 時間） |
| `F` | 全螢幕 |
| `Home` / `End` | 第一頁 / 最後一頁 |

> 練習時開 `N` 看講稿；正式報告時關掉即可。講稿只有你自己看得到（在畫面下方浮出）。

## 15 分鐘節奏（共 20 頁）

| 段落 | 頁 | 時間 |
| :--- | :--- | ---: |
| 開場 + 定位 + 架構 + Agenda | 1–4 | ~3:30 |
| **① SSE 生產者–消費者解耦** | 5–7 | ~2:45 |
| **② LangGraph 雙模型 Agent** | 8–10 | ~3:15 |
| **③ Hybrid RAG（Qdrant）** | 11–13 | ~3:45 |
| **④ Context 工程 + 認證 / 配額** | 14–18 | ~5:25 |
| 總結 + Q&A | 19–20 | ~1:00 |

合計約 **15 分鐘**（各頁時間見講稿右上角），留 15–20 分鐘問答。
若時間緊，優先壓縮 1–4 頁（架構帶過）與第 7、10 頁。

## 每段最想被記住的一句

- **SSE**：把「對話要不要繼續產生」（業務邏輯）與「使用者有沒有在看」（連線狀態）解耦。
- **LangGraph**：讓貴的模型（Analyst / gpt-5）只在最關鍵那一步出手，便宜模型（Router / gpt-5-mini）不寫長文。
- **Hybrid RAG**：dense 抓語意、BM25 抓精確詞（如「2330」），用 RRF 融合排名；uuid5 讓管線冪等。
- **Context / 認證 / 配額**：優化用 `token_usage_logs` **量化驗證**；RT rotation 靠**原子消費**偵測重放；配額**允許單輪略超、最終一致**。

## Q&A 可能被追問（先想好答案）

- RRF 的分數尺度為何不能直接相加？`k` 參數影響？
- 背景任務可靠性：目前同 process，如何擴到多 worker / job queue？（設計文件「方向 C」）
- Token reuse 全撤 session 會不會誤傷本人？→ 會，這是刻意取捨（無法區分誰先用）。
- 配額「允許略超」如果被大量濫用怎麼辦？→ pre-flight 擋下一輪 + 併發上限。
- Parent DAG 如何支援「重新生成」與版本切換 `< 1/2 >`？Recursive CTE 如何回溯乾淨分支？
- Lambda 冷啟動 / embedding 逾時如何處理？→ fail loud + 重跑補齊（冪等）。
